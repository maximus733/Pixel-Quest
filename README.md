# Pixel Quest 🎮

A tiny original 8-bit-style platform game built with vanilla HTML, CSS, and JavaScript. No frameworks, installs, or copyrighted game assets required.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Controls
- **← / →** or **A / D** — move
- **Space / ↑ / W** — jump
- **Enter** — start
- **R** — restart
- On mobile, use the on-screen buttons.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example, `pixel-quest`).
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the published URL to appear in the Pages section.

## Customize it
- Edit `platforms`, `stars`, `enemies`, and `goal` in `game.js` to change the level.
- Change colors in `style.css`.
- The character and scenery are drawn with Canvas rectangles, so you can remix the pixel art directly in `game.js`.

Have fun and make it yours!
